# Salon photos

Drop the original photos here (JPG or PNG, straight from the camera/phone —
no need to resize or crop them first). They are then cropped, converted to
WebP and listed in `salon-data.js`.

Suggested names:

- `nails-01.jpg`, `nails-02.jpg` … — finished nail work (Our Work gallery)
- `salon-01.jpg` … — the salon, staff at work, clients being served
- `polish-01.jpg` … — polish wall / colour stock
- `menu.jpg` — the printed price menu
